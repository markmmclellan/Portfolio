V-Calc: Pokémon Champions Damage & Speed Calculator

A Showdown-style damage and turn-order calculator for Pokémon Champions, built with React and TypeScript on top of the @smogon/calc Champions ruleset. Pulls live usage data from op.gg via a custom scraper so popular moves, items, abilities, natures and Stat Point spreads apply in one click, supports Doubles with spread-move handling, team import/export from Showdown pastes, and saved presets. Deployed to GitHub Pages with a scheduled workflow that rebuilds every 6 hours to keep the data fresh.

Self Hosted Local LLM & Interface Stack

An end-to-end local AI environment running on my own hardware. Koboldcpp serves a Gemma 4 12B (QAT) model as an API backend, and SillyTavern provides the front end for session management and prompt customization. I reach it from my phone from anywhere over Tailscale.

Phone Browser, from anywhere
Tailscale WireGuard-encrypted mesh, no open ports
Home PC RTX 5080 16 GB · 32 GB RAM
  • SillyTavern (front end)
  • Koboldcpp (API backend)
  • Gemma 4 12B QAT

Security

I used Tailscale instead of port forwarding, so nothing on my home network is exposed to the public internet. Only my own authenticated devices can reach the model.

What I learned

I originally built it as a coding assistant, but models this small turned out to be poor at coding work. I repurposed it for creative writing and recreation, which is where it shines.
